# 同步与防回环模式

本文件是跨案例设计指导，不表示其中每个完整拓扑均已实机验证。具体运行结论以案例和实验的证据状态为准。

## 单向属性镜像

```text
源属性更新 → 可选转换 → 目标属性写入
```

只有在类型、单位、量程和步进一致时才可直接镜像；否则先转换和夹紧。

## 双向同步

最小差值门控：

```text
A 或 B 更新 → 标准化 A/B → 比较差值
不同 → 由触发侧写目标侧
相同 → 停止
```

差值为 0 只能说明稳态相等，不能证明不存在回环。可靠设计还要考虑：

- 来源标记或执行锁。
- 去抖与节流。
- 浮点容差或离散档位。
- 设备夹紧、量化和拒绝值。
- 双方同时操作的优先级。
- 离线恢复和启动时初值竞争。
- 最大操作次数或收敛监控。

## 开关状态

仅当双方严格归一为 0/1 时可用简单差值。未知值和第三状态必须单独处理。

## 单主多从和状态驱动切换

多设备保持一致时，优先选一个事实源，其他设备只单向跟随，避免全互联回环。短延时只能吸收部分通知时序，不能替代重试、最终校验和快速连续操作测试。

设备存在多个外部控制入口时，内部模式位置不能当作设备真实状态。按最近已知设备状态查询下一档，并为未知、离线、未覆盖区间设计兜底。连续值先分成无重叠、无空洞的离散区间。

## 数值参数

比较前先转换到同一规范量程。双向有损映射可能永远不完全相等，应使用容差或离散档位，不能严格 `!= 0`。

## 颜色值

不同设备可能使用十六进制文本、十进制整数或厂商编码。没有经过双方能力验证和可逆转换时，只做单向同步。
