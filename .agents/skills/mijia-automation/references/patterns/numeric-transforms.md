# 数值变换模式

本文件是跨案例设计指导，不表示其中每个完整拓扑均已实机验证。具体运行结论以案例和实验的证据状态为准。

## 原始值与派生值

```text
设备值 → 原始变量 → 数值运算 → 派生变量 → 判断/动作
```

保留原始值便于排障；派生变量应注明单位和量程。

## 取整与小数量化

- 整数：`round(x)`、`floor(x)`、`ceil(x)` 按需求选择，三者不可互换。
- N 位小数：`round(x * 10^N) / 10^N`。

这是数值量化，不保证文本显示固定尾零。`.5`、负数和浮点误差需要独立测试。

## 量程转换

严格端点映射使用仿射公式：

```text
y = c + (x - a) * (d - c) / (b - a)
```

把 `[a,b]` 映射到 `[c,d]` 后，再按目标类型取整、按步进量化并夹紧范围。

禁止仅凭 `x * d / b` 处理非零下限；例如 `[1,100]` 与 `[1,65535]` 不能精确用 `x*655.35` 双向映射。

## 非线性变换

`pow`、`log` 和三角函数只有在有明确物理模型或标定数据时使用。平方照度不是通用的人眼感知曲线；必须定义系数、限幅和目标设备范围。

## 文本前的数值准备

播报前完成：

1. 单位换算。
2. 取整或小数量化。
3. 异常值和未初始化处理。
4. 再进行文本拼接。

不得把视频中的演示算式直接视为已验证公式。

## 分段渐变和终点夹紧

按周期累加实现渐变时，向上取整步长会产生终点超调。每轮都应夹紧：

```text
上升：next = min(target, current + step)
下降：next = max(target, current - step)
```

还要验证总周期数大于零、目标量程和步进合法，并在每段开始时明确初始化或按当前时间直接计算理论值。
